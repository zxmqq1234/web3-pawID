# PawID 纯前端交互演示

PawID 是一份面向宠物的数字生命护照概念演示：把宠物身份、家庭共同监护、成长记录、模拟成长资产、防丢协作和服务生态放在同一条可理解的体验链路中。它用 Web3 的身份连续、授权和可验证记录表达产品价值，但不要求用户理解链上技术。

## 演示边界与价值

- 这是纯前端演示，不连接真实区块链、钱包、支付、通知、定位或机构系统。
- Monad、身份账户、交易 ID、PAWS、机构凭证、AI 形象和服务意向均为预置/模拟/示例数据。
- 数据用于展示产品交互与 Web3 价值，不代表真实认证、真实交易、真实医疗或真实机构合作。
- 资源使用项目内原创 SVG 与预置素材；原创 SVG 统一作为宠物肖像、预置宠物肖像和界面插图展示，不称为真实照片。

## 环境与运行

需要 Node.js 与 npm。建议使用当前 LTS 版本。

```bash
npm ci
npm run dev
npm test -- --run
npm run build
```

应用使用 `HashRouter`，开发服务器和静态部署刷新后都可以从 `#/` 路由进入。演示状态使用 `localStorage` 保存，用户上传图片使用 IndexedDB 保存；同源同浏览器的多标签页可通过 storage 事件同步状态，不同浏览器、不同设备不会实时同步，也不会自动迁移本地数据。

本项目不需要 API Key、钱包、助记词或外部服务账号。

## 五分钟完整演示

1. **创建身份**：首页点击“创建 PawID”，选择示例猫咪或示例狗狗，确认资料，生成预置数字形象并完成创建。创建过程是本地模拟，完成后回到宠物工作台。
2. **共同监护**：进入 Mochi 的“家庭族谱”，以主监护人身份邀请家人，生成邀请链接；打开链接进入邀请确认页。
3. **父亲关系**：回到族谱，添加一只符合条件的预置宠物作为父亲；关系先显示为待确认，再用演示控制切换角色或模拟接受，观察族谱和成长任务变化。
4. **成长记录和兑换**：进入“生命档案”，新增一条手动成长记录；到“成长资产”查看 PAWS、徽章与积分流水，完成任务后预览并兑换装扮，再切换到衣橱穿戴。
5. **走失线索与接回**：进入“防丢守护”，标记 Mochi 走失，打开 PawTag 访客页，以访客身份填写发现地点和留言；回到工作台查看线索，并以主监护人确认接回，观察 Home Again 徽章。
6. **生态意向**：进入“服务生态”，浏览宠主、机构和公益三类服务方向，打开详情并记录感兴趣。意向仅保存于本地，不创建订单或发生交易。

顶部或公开页底部的“演示控制”可切换主监护人、受邀者和访客，注入下一次操作失败，或重置当前浏览器的演示状态。邀请确认必须先切换到“模拟受邀者”；PawTag 只展示必要公开资料，不泄露账号、地址、健康档案、家庭成员或私密描述。

## 路由

- `#/`：首页
- `#/create`：创建 PawID
- `#/pets/:id?tab=overview|family|life|assets|safety`：宠物工作台
- `#/invite/:inviteId`：邀请确认公开页
- `#/tag/:id`：PawTag 访客公开页
- `#/ecosystem`：服务生态
